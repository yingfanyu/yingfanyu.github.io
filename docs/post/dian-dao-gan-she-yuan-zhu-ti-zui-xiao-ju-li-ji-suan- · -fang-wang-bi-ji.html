点到干涉圆柱体最小距离计算 · 防忘笔记

配套表格：点到干涉圆柱体的距离计算.xlsx（Sheet1）。本笔记按表内 A18:A39 的八步注释整理，并修正了注释中的笔误、标出了公式陷阱。

一、已知量与符号约定

量 表格位置 本例数值
刀心点坐标 C（贴刀心那一刃） B3:D3 (89.881894, 3.789083, −17.187633)
刀轴单位矢量 u = (i, j, k) G3:I3 (0.455705, 0.881805, −0.12146)
圆柱直径 D / 厚度 T / 棱圆角 r M3 / N3 / O3 125 / 3.18 / 0.8
偏置方向 s（正刀 +1，反刀 −1） P3 −1（注释 A18 用的是 +1，见坑 4）
点云点 P G7:I7 (48.2872, 20.415958, −60.500537)

由尺寸推两个内芯参数（所有后续判据都基于它们，不是基于 R=62.5）：

a = D/2 − r      = 125/2 − 0.8 = 61.7    ← 内芯半径（L7）
b = (T − 2r)/2   = (3.18 − 1.6)/2 = 0.79  ← 内芯半高（M7）

实体心：C_ent = C + u · (s·T/2)。即沿刀轴走"厚度一半 × 偏置方向"，s=+1 走 +1.59，s=−1 走 −1.59。

二、八步计算流程

① 实体心（对应 A19:A21，s=+1 的值）

x = 89.881894 + 0.455705×1×3.18/2 = 90.606465
y = 3.789083  + 0.881805×1×3.18/2 = 5.191153
z = −17.187633 + (−0.12146)×1×3.18/2 = −17.380754   （B7:D7）

② 相对坐标 V = P − C_ent（A23:A25）

V = (−42.319265, 15.224805, −43.119783)   （B11:D11）

坑 1：A25 写成 +43.1197，实际是 −60.5005 − (−17.3808) = −43.1197。A27/A29 用的是负值，是对的。

③ 点到实体心的距离 D_v = |V|（A27，F11）

D_v = √(42.319265² + 15.224805² + 43.119783²) = 62.305943

④ 轴向距离 h = V·u（A29，B14）

h = −42.3193×0.455705 + 15.2248×0.881805 + (−43.1198)×(−0.12146)
  = −0.622463

u 是单位矢量，所以点积直接是 mm，不用再除 |u|。

⑤ 到刀轴垂距 d（A30，D14）

d = √(D_v² − h²) = √(62.305943² − 0.622463²) = 62.302834

坑 6：勾股反推依赖 |u|=1，本表 J3=0.9999998 并非严格 1。严谨写法（与代码一致）是正交分解：
d = √((Vx−h·i)² + (Vy−h·j)² + (Vz−h·k)²)

⑥ 内芯半径/半高 → a=61.7、b=0.79（A32:A33，L7/M7）

⑦ dd 与 hh（A35:A36，F14/G14）——都做了 max(·,0) 钳位

dd = max(d − a, 0)      = max(62.302834 − 61.7, 0) = 0.602834
hh = max(|h| − b, 0)    = max(0.622463 − 0.79, 0)  = 0

⑧ 最小距离 L（A38:A39，I14/L14）——见下一节。本例 I14=L14=−0.197166。

三、两套公式与适用条件（最容易忘）

公式①（I14，通用精确式）

L = √(dd² + hh²) − r

点在实体外或圆角/侧面/端面壳层内时，这就是精确最小距离，无需分区。

坑 2：A38 写成 √(dd²+hh²) + 0.8，"+"是笔误，应为 − 0.8（结果 −0.197166 是对的）。

公式②（L14，注释里当成备用式）

L = SIGN(I14) · ( r + min(a − d, b − |h|) )

坑 3：A39 注释称此式"只有到轴线距离＜内芯半径时适用"。本例 d=62.30 大于 a=61.7，并不满足该前提，公式却碰巧给出了正确值。这个适用条件写错了。

公式②的真实适用范围（推导：把 min 的两种取值代回）

点所在区域 L14 是否等于精确值
芯部内（d≤a 且 |h|≤b） ✓ 等于 −(r+min)，即精确侵入深度
仅径向超出（d>a、|h|≤b） ✓ 退化成 I14
仅轴向超出（d≤a、|h|>b） ✓ 退化成 I14
双超出圆角区（d>a 且 |h|>b） ✗ 不等于 √(dd²+hh²)−r
实体外部 ✗ 符号会反过来（给出负值）

实测反例：把 P3 改成 −1 时，d=62.3028、|h|=2.5575（双超出且点在实体外），I14=+1.067510 正确，而 L14=−0.967536 错误。

结论：日常只用公式①就够了。 只有需要"点在芯部内时的真实侵入深度"才用精确统一式：

L_exact = IF( AND(d<=a, |h|<=b),
              −( r + MIN(a−d, b−|h|) ),       ← 芯部内，精确侵入深度
              √(dd²+hh²) − r )                 ← 其余，精确距离

表内 点到干涉圆柱体的距离计算_修正版.xlsx 的 J14 已是这个式子，K14 给出它与 I14 的差值。

四、最高频的 6 个坑（速记）

  1. z 相对坐标符号：P_z − C_z 两负相减得负，别漏负号（A25）。
  2. A38 的 "+"：是 − r 不是 + r。
  3. A39 的适用条件：写反了，公式②不是给"d<a"用的；点在实体外时它会给错符号。
  4. 偏置方向符号：注释 A18:A21 按 s=+1 写，表格 P3=−1。改 s 时实体心整体沿 u 移 T=3.18 mm，点没动，h 会变，判据结果也随之变——这不是算错。
  5. 钳位值 −0.8 不是实测深度：ToolDist 在芯部内把距离钳成 −r，真实侵入深度是 −(r+min(a−d,b−|h|))。本例 s=+1 时两者恰好都是 −0.1972，是因为点在壳层内；只有在芯部内两者才有差别。
  6. d 用正交分解更稳：勾股反推 √(D_v²−h²) 依赖刀轴严格单位化；本表 J3≈0.9999998，有微小误差。
