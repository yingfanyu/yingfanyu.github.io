德马吉海德汉系统后处理前一个操作有C角度，后一个操作是0,0,1刀轴时候的处理

问题一：
德马吉海德汉系统后处理当前有一个问题，当前一个操作有C角度（PLANE SPATIAL SPA ......），后一个操作是0,0,1刀轴时候. 后一个操作在处理的时候会把前面的C轴角度继承下来，B轴为0 。此时XYZ定位的坐标系是B0C0的，但是工件却转了一个角度，工件中心不在C轴中心的时候就会出错。
解决方案：①post builder打开相应后处理，在custom command页面下找到PB_CMD_revise_new_iks,在右侧把# set mom_kin_rotary_axis_method "ZERO"前的#号去除掉，就会把C轴每次都回到C0就能解决这个问题。②在刀具路径结束块加入一下custom command命令 # Stage for MOM_reload_kinematics

global mom_prev_pos
global mom_pos
global mom_prev_out_angle_pos
global mom_out_angle_pos
global mom_prev_rot_ang_4th
global mom_prev_rot_ang_5th
global mom_rotation_angle

set mom_prev_pos(0) 0.0
set mom_prev_pos(1) 0.0
set mom_prev_pos(2) 0.0
set mom_prev_pos(3) 0.0
set mom_prev_pos(4) 0.0

set mom_pos(0) 0.0
set mom_pos(1) 0.0
set mom_pos(2) 0.0
set mom_pos(3) 0.0
set mom_pos(4) 0.0

set mom_prev_out_angle_pos(0) 0.0
set mom_prev_out_angle_pos(1) 0.0

set mom_out_angle_pos(0) 0.0
set mom_out_angle_pos(1) 0.0

set mom_prev_rot_ang_4th 0.0
set mom_prev_rot_ang_5th 0.0

set mom_rotation_angle 0.0

MOM_reload_variable -a mom_prev_pos
MOM_reload_variable -a mom_pos
MOM_reload_variable -a mom_prev_out_angle_pos
MOM_reload_variable -a mom_out_angle_pos
MOM_reload_variable mom_prev_rot_ang_4th
MOM_reload_variable mom_prev_rot_ang_5th
MOM_reload_variable mom_rotation_angle

MOM_reload_kinematics
把相关的XYZ坐标和旋转轴都清零，并且告诉后处理内核这些变量我都更新了，用新变量值，用这种方法也可以清理当前操作结束后的所有状态，也能达到相应的要求。

问题二：
在打枪钻的时候，会设置进刀条件为主轴s100，进给100，到开钻深度后提转速和开中心出水，钻到底之后停主轴和中心出水，再抬刀出来，在默认后处理里输出了M5和M9之后，后处理内核并不认为已经关闭主轴了，所以在有两个以上的深孔钻的时候，移到下一个位置的时候会再次输出一个M3旋转主轴，此时的模态转速还是较高转速，很容易出现甩出枪钻的事故，所以需要在控制事件M5之后再加一行custom command命令，命令如下global mom_spindle_direction
set mom_spindle_direction OFF 告知内核主轴已经停了，这样钻完一个孔移动到另一个位置的时候就不会再次输出M3，可以避免此类事故。
