## 0. 三分钟速览

| 要校的东西 | 存到哪 | 靠什么算出来 |
|---|---|---|
| 测球触发半径 X / Y | `#500` / `#501` | 赤道四点 + 闭式解 |
| 测针偏心 X / Y | `#502` / `#503` | 赤道四点（与半径同源） |
| 刀长 | 对应刀补区 `+#11000+T` | 触球顶得到 Δ，累加到刀补 |

整趟只碰球 **6 次**：粗触顶 1 + 赤道 4 + 顶测 1。（旧版 10 次，多的 4 次是预对中，已删，理由见 [3.9](#39-那-4-次预对中到底该不该有)）

三条最容易被忘记的结论：

1. **必须在赤道测**——不是"差不多在赤道"，是「测球中心」严格落在过球心的水平面上。偏了，法向就斜了，触发方向与将来测孔不一致。
2. **V 有错，半径就错**——公式对 V 很敏感：V 差 3 mm，半径差约 320 µm。所以 V 必须用**实测球心**（`#160`）算，不能用名义球心。
3. **刀补最后写**——写完刀补，所有"依赖旧刀长"的动作就都不能再做了。程序里写刀补是倒数第二个动作，写完只剩抬刀。

## 1. 校准原理

### 1.1 触发式测针"报"的到底是什么坐标

这是所有误差的源头，必须先拧清楚：

- **X / Y**：触发瞬间，机床报的是**测球中心**的位置。所以测孔时算半径要 `+r`，测外圆要 `−r`。
- **Z**：刀长补偿对的是**测球最低点（球底顶点）**，不是球心。所以程序里的 Z 坐标 = 球底的高度，**球心比它高一个 r**。

这一条直接决定了后面所有公式里那个"减 r"从哪来（见 [2.3](#23-z-坐标约定为什么指令要减-r)）。

### 1.2 三个量，三种测法

| 量 | 物理含义 | 怎么测 |
|---|---|---|
| 触发半径 `r` | 测球中心到"电子触发点"的距离（不是磨出来的实际球半径，是触发瞬间的有效半径） | 赤道四点，配对求半跨 |
| 偏心 `EX/EY` | 输入球心与"主轴读到的球心"之差 = 球心填表偏差 + 测球偏心 | 赤道四点的中点 vs 输入球心 |
| 刀长偏差 `Δ` | 刀补与实际长度的差 | 球顶单点触碰 |

三者**共用同一颗球、同一次装夹、同一次运行**，这就是"用球"的核心价值：不用换器具、不用重找零点。

> **`#502/#503` 里装的不是纯测球偏心。** 它是 `输入球心 − 中点 = Δ + E`：
> `Δ` 是球心填表偏差，`E` 是测球偏心。球心填得准（`Δ≈0`），它就是纯 `E`；
> 球心填偏 0.5 mm，它就被污染 0.5 mm。所以"用中心寻找规把球心测准"不只是为了算半径，
> 也是为了这条参数本身。
>
> 反过来，`E` 多大都不影响**半径** —— 半径用的是两触点之**差**，`E` 同时平移两点，相减抵消。

### 1.3 为什么必须是赤道

<img width="720" height="460" alt="Image" src="https://github.com/user-attachments/assets/67483e32-c7a1-4ab1-a5c4-7237eda84b79" />

接触法向 = 球心到测球中心的连线方向。只有当测球中心和球心**等高**时，这条线才是水平的。

- 赤道上：法向水平 → 测球沿水平方向压向球面 → 与将来测孔壁、测凸台侧面**完全同条件**。探针的方向性差异（预行程、各向触发力不同）在这种同条件下自动抵消。
- 偏离赤道：法向倾斜 θ → 触发变成"横向 + 轴向"的混合 → 方向性误差按 sinθ 混进结果，标定条件 ≠ 使用条件。

> **这条是"校准条件必须等于使用条件"的直接应用。** 不是精度问题，是系统误差问题——它不会因为多测几次而变小。

### 1.4 为什么用球，不用环规

| | 环规 / 圆柱销 | 基准球 |
|---|---|---|
| 能校什么 | 只能校半径（侧壁竖直，Z 位置无所谓） | 半径 + 偏心 + 长度，一次装夹全干完 |
| 高度敏感 | 不敏感（这正是它的优点） | 敏感，必须精确落在赤道 |
| 器具成本 | 高（要一套） | 低（一颗球 + 证书） |
| 5 轴 / 万向测头 | 不适用 | 适用（球各向同性） |

Renishaw 的标准器具其实是**环规**（手册原文：*"The probe is positioned inside a calibrated ring gauge"*），环规侧壁竖直，所以"高度"这个问题在他们的标准流程里根本不存在。球是给 5 轴和自动标定用的，那时候就必须处理赤道问题——也就是本程序要解决的事。

## 2. 数学：从几何到闭式解

### 2.1 记号

| 记号 | 程序里 | 含义 |
|---|---|---|
| `Rs` | `#133` = D/2 | 基准球半径（已知，来自证书） |
| `r` | 待求 | 测球触发半径 |
| `S` | `#1`/`#2` | 两球球心距 = `Rs + r` |
| `D` | `#8`/`#9` | 实测水平半跨（两侧触点差的一半） |
| `Z` | `#154` | 本次测量的指令 Z（= 球底高度） |
| `Zc` | `#160` | **实测**球心 Z |
| `V` | `#6` | `Z − Zc − Rs` |
| `h` | —— | 测球中心高出球心的高度 |

### 2.2 几何关系

<img width="720" height="420" alt="Image" src="https://github.com/user-attachments/assets/d56d2710-546a-4d74-bfdb-575d0f96b4e0" />

触发瞬间两球外切，球心距 `S = Rs + r`。把它拆成水平、竖直两个分量：

```
S² = D² + h²          …… ①
S  = Rs + r           …… ②
h  = r + Z − Zc       …… ③   （因为 Z 是球底，球心比它高 r）
```

**这里就是第一个坑**：想直接算出 r，得先知道 h；可 h 里面就有 r（式③）。所以**不能直接开方**。

### 2.3 Z 坐标约定：为什么指令要减 r

<img width="720" height="380" alt="Image" src="https://github.com/user-attachments/assets/d44cc3d5-cd42-4324-ba60-197686dfd9a4" />

把三个高度摆在一起就清楚了：球心、测球中心、球底（指令 Z）。球心 = 球底 + r + h。

于是式③成立。程序里把平面摆在 `Zc − r定位`，就是为了让球底比球心低一个 r，从而让**测球中心正好落在赤道上**。

### 2.4 解方程：把 r 消掉

关键是引入 `V`，它的定义**故意多减了一个 Rs**：

```
V ≡ Z − Zc − Rs
```

那么：

```
S + V = (Rs + r) + (Z − Zc − Rs) = r + Z − Zc = h     …… ④
```

**r 被消掉了。** 这一步是整个推导的核心——把"含未知量 r 的 h"换成"含未知量 S 的 (S+V)"，因为 S 和 r 之间只差一个常数 Rs。

代回式①：

```
S² = D² + (S + V)²
S² = D² + S² + 2SV + V²
 0 = D² + 2SV + V²
S  = −(D² + V²) / (2V)
r  = S − Rs
```

程序里就是这三行：

```
#6=#154-#160-#133              V = Z − Zc − Rs
#1=[[#8*#8]+[#6*#6]]/[-2*#6]   S = −(D²+V²)/(2V)
#159=#1-#133                   r = S − Rs
```

> **注意符号**：`V` 恒为负（因为 `Z − Zc ≈ −r`，再减 Rs 更负），所以 `−2V` 是正的，`S` 是正的。若 V 接近 0，说明测球中心跑到球极点附近，公式发散——程序里 `|V| < 1mm` 直接报 96。

### 2.5 赤道处的退化

如果平面**真的**在赤道（`r定位 = r`），那么：

```
V = −(Rs + r) = −S
S = (D² + S²)/(2S) → S² = D² → S = D
r = D − Rs
```

退化回最朴素的形式。这说明闭式解是**通用式**，名义半径法只是它 `h = 0` 的特例。

### 2.6 对旧半径的免疫力

代入 `Z = Zc − r定位`：

```
V = −(r定位 + Rs)，  S + V = r − r定位 = h
```

不管 `r定位` 取什么值，`S + V` 永远等于真实的 `h`。所以：

- 旧触发半径 `#500` 错得再离谱，`S` 解出来依然精确等于 `Rs + r`；
- 当时用 20 万组随机数（Rs、r、r定位 全随机）验证过，**误差恒为 0**（只受浮点尾数影响）。

**含义**：`R` 参数（名义测球半径）不是"计算输入"，只是"定位依据"。它错了，数还是对的，只是触点的法向不再水平（见 [3.8](#38-为什么可以给一个名义半径却又不影响结果)）。

## 3. 今天真正纠结过的 9 个点

这一节是这份笔记的主体。把当时卡住的地方按顺序记下来，下次直接跳到这里。

### 3.1 为什么是 `Rs + r`，不是 `Rs − r`

最初照着 9803（**内孔**环规）的写法抄了一个 `Rs − r`，代进去得到荒谬结果，还以为必须"回代迭代"。

- 内孔：测球在孔内，测球中心到孔壁距离 = `R孔 − r`（**减**）
- 外球：测球在球外，两球外切，球心距 = `Rs + r`（**加**）

符号一改，立刻变成闭式解，**迭代方案整个作废**。教训：先判断"测头在内侧还是外侧"。

### 3.2 Z 指令为什么要减 r

因为**刀长补偿对的是测球最低点，不是球心**（[1.1](#11-触发式测针报的到底是什么坐标)）。程序写 `Z = Zc − r`，物理上就是"球底落在球心下方 r 处"，等价于"测球中心落在赤道上"。

当时的疑问是"顶点要在球心下方 r 处，测球中心才在赤道"——这句话里的"顶点"指的就是球底顶点，没毛病，只是说法容易歧义。

### 3.3 V 为什么要多减一个 Rs

不是物理，是**代数技巧**。多减一个 Rs，才能让 `S + V` 恰好等于 `h`，从而把 r 从方程里赶出去（[2.4](#24-解方程把-r-消掉)）。

如果 V 定义成 `Z − Zc`，那 `S + V = Rs + r + (Z−Zc)`，r 还赖在里面，方程就解不动了。

### 3.4 为什么不能"触发瞬间直接读 h 和 D"

D 能直接读，h **不能**——h 是"测球中心到球心"的竖直距离，而球心位置本身要靠触顶得到，且 h 里含未知的 r。表观上"两球相切，量一下不就完了"，实际上缺一个方程。

**绕的这一下（引入 S+V）不是多余，是把未知量 r 替换成未知量 S 的唯一办法。**

### 3.5 V 没用实测球心的 bug

早期版本 V 里用的是**名义球心** `Zc`，而不是触顶后的实测球心 `#160`。后果：

```
Δ = 3 mm 时不修正 → 半径错约 0.32 mm（320 µm）
而且这个错值还能通过 2 mm 的防呆门限，静默写进 #500
```

修正办法：`#160` 在粗触顶、长度两步里逐级更新，V 直接用 `#160`：

```
#6=#154-#160-#133
```

**教训**：凡是"球心"出现的地方，一律用 `#160`，不要用 `#132`（#132 只是入口给的名义值）。

### 3.6 偏心为什么必须和半径同源

当初程序里本来有两组四点：`0.5Rs` 高度一组（粗对中）、赤道一组（正式）。偏心若取自前者，
数值上差得不多，但物理含义完全不同：

- 偏心的定义是"测球球心相对主轴轴线的偏移"，将来**任何方向**的测量都会带着它；
- 触发性能随方向变化：法向斜的触点，等效触发点与法向水平的触点不一样；
- 所以只有在**与将来测量同条件**（法向水平）下测出来的偏心，才是那个会被重复带出去的偏心。

这一版把 `0.5Rs` 那组整个删掉后，这个隐患自动消失了 —— 半径和偏心来自同一组赤道四点，
不存在"取错来源"的可能。删掉的依据见 [3.9](#39-那-4-次预对中到底该不该有)。

### 3.7 为什么刀补必须最后写

写刀补会改变 `#116`（当前刀长），而程序里所有 Z 坐标都是"程序坐标 = 机床坐标 − #116"。一旦改了 `#116`：

- 安全高度 `#160 + Rs + Q` 的含义就变了；
- 起点高度 `#157` 的含义也变了（所以最后一步要 `Z[#157 - Δ]` 才是回到原高度）。

所以顺序被固定死：**测量 → 写参数 → 退刀 → 写刀补 → 抬回起点（减 Δ）**。

### 3.8 为什么可以给一个名义半径，却又不影响结果

这是今天最后加的 `R` 参数（详见 [7](#7-变更记录)）。逻辑链：

1. `R` 只决定"平面摆在哪"，进不了公式（[2.6](#26-对旧半径的免疫力)）。
2. 摆错平面 → `h ≠ 0` → 但 `S + V` 仍然等于真实的 `h` → 解出来的 `r` 仍然精确。
3. 所以 `R` **填错不影响数值**，只影响"法向是否水平"。
4. `R` 太大（超过球半径）→ 平面落到球底下 → 根本不触发 → 现有 93 报警兜住。

那为什么还要它？**为了让赤道条件真正成立**，而不是让数字对。尤其是换测针首次运行时，旧 `#500` 可能差好几个毫米，此时不给 `R`，平面会明显偏离赤道。

### 3.9 那 4 次预对中到底该不该有

这个问题问了两层，第二层比第一层更值得记。

**第一层：它有什么用？**
旧版有「`0.5Rs` 高度四点，结果不保存」。它唯一的作用是：把轴摆到球心，让紧接着的顶测
落在真球顶，而不是落在斜面上。顶测若偏 `e`，球顶会被测低 `e²/2(Rs+r)`
（测球中心沿的球面半径是 `Rs+r`，不是 `Rs`；`Rs≫r` 时就是常见的 `e²/2D` 那个近似）：

| 球心 XY 偏差 e | 顶测偏低 |
|---|---|
| 0.1 mm | 0.4 µm |
| 0.5 mm | 8.9 µm |
| 1.0 mm | 36 µm |
| 2.0 mm | 143 µm |

这个误差会进 `Δ长`、进刀补、进后面所有 Z 向测量。所以"顶测必须在真球顶"是硬要求，
那 4 次不是为了对中而对中，是为了这个。

**第二层：能不能换个更便宜的方式满足它？**
能，但理由要说得更准一点 —— **中点不等于球心，它等于「球心 − 测球偏心」**。

三个量分开：`C` = 球心物理位置，`Δ` = 起测点（输入球心）偏了多少，`E` = 测球偏心。
两侧触发时主轴读数是 `C ± Rh − E`（`Rh = sqrt((Rs+r)²−h²)`），相加除二得 `C − E`：
`Δ` 整个消失，但 `E` 留着。

关键在这：程序算的 `#144 = 输入球心 − 中点 = Δ + E`，正好把两个偏差一起兜住。
所以顶测定位到 `#130 − #144` 时，主轴落在 `C − E`，**测球球心精确落在 `C`**。
而半径用两点之**差** `2Rh`，`E` 相减抵消，一点不被污染。

换句话说：中点不是球心，但它加一个固定偏移后**就是我们要的那个量**，而且不随起测位置变。
所以顺序倒过来即可：

```
旧：粗触顶 → 0.5Rs 四点（对中） → 顶测 → 赤道四点（半径+偏心）
新：粗触顶 → 赤道四点（半径+偏心，顺手得到球心位置） → 顶测
```

`0.5Rs` 那 4 次就变成纯冗余，删掉，10 次变 6 次。

**代价只有一条**：赤道平面的高度基准从 `Δ长`（精）变成 `Δ粗`（粗），两者差 `e²/2(Rs+r)`。
这个差会让半径解产生残差（端到端模拟，Rs=12.5、r=1.5）：

| 球心 XY 偏差 e | 给了 R（r定位 = r） | 没给 R，旧半径差 1 mm |
|---|---|---|
| 0.1 mm | 0.00 µm | 0.03 µm |
| 0.5 mm | 0.00 µm | 0.7 µm |
| 1.0 mm | 0.05 µm | 2.7 µm |
| 2.0 mm | 0.7 µm | 10 µm |

也就是说：**给了 `R`，几乎回到"数学上严格 0"**；没给 `R` 且球心偏 1 mm 才有 3 µm。
而偏 2 mm 会撞上 95 报警门槛，不会静默通过。

**顺带回答"为什么偏偏是 0.5Rs"**：没有依据，是个折中。对中精度与高度无关（中点性质），
高度只影响三件事 —— 触点法向倾角、起测点安全余量、对平面高度误差的敏感度。
水平圆半径 `sqrt((Rs+r)²−h²)` 对 h 的导数在极点趋无穷、在赤道为 0：

| 高度 | 水平圆 | 法向 | 对 Z 误差的敏感度 | Z 容错 |
|---|---|---|---|---|
| 0.7Rs | 0.71Rs | 44° | 大 | ±0.7Rs |
| 0.5Rs | 0.87Rs | 30° | 中 | ±0.5Rs |
| 0.1Rs | 0.995Rs | 5.7° | 最小 | ±0.1Rs |

`0.6Rs` / `0.7Rs` 没有任何理由（更靠极点、更敏感）。真要保留，`0.1Rs` 在数学上更好
（Rs=12.5 时 Z 余量仍有 1.25 mm，远大于 `Δ粗` 的几十 µm）。但既然已经删了，这条只作备忘。

## 4. 程序结构

### 4.1 流程

### 4.2 为什么是这个顺序

刀长未知时，**唯一能盲触的方向是正上方**——球顶是最高点，从上面下来必然碰到，不会撞侧面。
所以第一步只能是触顶，没有别的选择。

1. **粗触顶**（`U` 可关）→ 拿到 Z 基准，赤道平面才有高度可摆；
2. **赤道四点** → 半径 + 偏心；这一步**不需要先对中**，因为中点不随起测位置变，而且 `#144` 把测球偏心一并算进去了；
3. **顶测长度** → 定位到 `#130−#144`（测球球心对准真球心），触在球顶而不是斜面，`Δ` 才干净。

**每一步都在为下一步消除一个未知量**：粗触顶消除"球大概在哪"，赤道四点消除"球心到底在哪、半径多少"，
顶测消除"刀长差多少"。旧顺序在这三步之间多绕了一圈（先对中 → 再顶测 → 再回赤道），
新顺序是一条直链，所以能省下 4 次触发。

三条硬约束把这个顺序钉死了，破坏任何一条都会引入 µm 级误差：

- **顶测必须在真球心正上方** —— 否则球顶被测低 `e²/2(Rs+r)`（e=0.5 mm 就 8.9 µm）；
- **赤道四点的平面和 V 必须用同一个球心基准** —— 混用会引入 `ε` 失配（见 [2.6](#26-对旧半径的免疫力)）；
- **刀补必须最后写** —— 见 [3.7](#37-为什么刀补必须最后写)。

### 4.4 安全设计

| 机制 | 做法 | 防的是什么 |
|---|---|---|
| 所有移动走 9810 | `G65P9810...F#119`，带到位检测 | 撞刀、程序错位（报 86） |
| 起测点在球外 | `球心 ± (Rs + r定位 + Q)` | 从球外进刀，不依赖旧半径准不准 |
| 第一次触球就在赤道 | 上面那条公式，Q 默认 5 mm | 赤道是球最宽处，余量最小（只剩 Q−球心偏差）；球心坐标不可靠时把 `Q` 给大，如 `Q10` |
| 抬刀判断 | `IF[#1LT#157]` 才抬 | 已经在高处就不再动 |
| Δ 上限 K | `ABS[Δ] > K` 报警 94 | 球装错、坐标填错、探针没开到位 |
| 偏心门限 | 新旧差 > 2mm 报警 95 | 换了大号测针、球心填错 |
| 半径门限 | <0.2 或 >10 或与基准差 >2mm 报警 96 | 公式发散、极端输入错误 |
| 刀补最后写 | 写完只剩抬刀 | 改完刀长还用旧值算坐标 |

| 号 | 含义 | 最可能的原因 |
|---|---|---|
| 86 | 路径受阻（9810 内部） | 目标点与实际位置差太多，撞到了 |
| 91 | D 或 T 没给 | 调用格式漏参数 |
| 92 | 探针未开 | 忘了开探针 / 电池 |

| 95 | 偏心超限 | 球心 X/Y 填错、球装偏 |
| 96 | 半径超范围 | V 接近 0、D 填错、换错测针 |

## 5. 传统方法 vs 本法

### 5.1 传统怎么做（Renishaw / Mazak O8002 一类）

1. 程序先让**主轴转 180°**，用同一点两次触碰求出主轴轴线（自找中心）；
2. 用**名义测球半径**把测球摆到"名义赤道"；
3. 测完直接 `r = D − Rs`（或等价的简化式）；
4. 全程不需要知道球心坐标。

**设计动机**：宏必须能在**任何一台机床、`#500 = 0` 的全新状态**下从零跑通。它唯一自带的参考就是证书上的球径。

### 5.2 我们怎么做

1. 球心 X/Y/Z 由操作者用**中心寻找规 + 块规**独立测出并输入；
2. 用这个球心定义赤道平面（可再用 `R` 精确定位）；
3. 测完用**闭式解**算半径，对旧值不敏感。

**设计动机**：这台机床的球心是**可以事先测准**的，那就不必在程序里"猜"。

### 5.3 对比

| 维度 | 传统（名义半径法） | 本法（实测球心 + 闭式解） |
|---|---|---|
| 球心来源 | 程序自找（180° 定向） | 机外独立测 |
| 赤道定位 | 名义 r，实际偏差 `h = r真 − r名义` | `R` 或旧值，公式自洽 |
| 半径算法 | 简化式 `r = D − Rs` | 闭式解 `S = −(D²+V²)/(2V)` |
| 对 h 的敏感度 | 误差 ≈ `h² / 2D` | **0** |
| 测球名义半径填错 1 mm | 静默错约 **36 µm** | **0**（只影响法向倾角） |
| 球心坐标填错 | 不受影响（不用球心坐标） | **1:1 全错** |
| 全新机床 `#500=0` | 能直接跑 | 需要一个初始值（旧值或 `R`） |
| 是否依赖外部器具 | 不依赖 | 依赖球心测量 |
| 代码复杂度 | 高（自找中心要多次定向） | 低（球心直接用） |

### 5.4 结论

**不是谁更科学，是约束不同。**

- 他们的约束是"通用、免前置条件"，所以愿意接受 `h` 带来的微小误差——而且这个误差在他们那儿确实可忽略：DIN 5401 Grade 5 的球径公差只有 ±5.32 µm（直径），名义半径与真值差不到 3 µm，`h²/2D ≈ 0.2 nm`，等于零。
- 我们的约束是"这台机床、球心能测"，所以把球心当已知量，换来的是**对输入错误免疫**和**赤道条件精确成立**。

真正的差别不在精度（两者都在 1～2 µm 量级），而在**鲁棒性方向**：他们怕"没基础"，我们怕"球心测错"。

![误差对比](img/fig5_error.svg)

上面这条红线只在"名义半径和真值差很多"时才有意义。他们的世界里 `h ≈ 0`，所以一直都在曲线原点附近；我们的世界里 `h` 可能是 1 mm（旧测针差一个型号），所以必须用不敏感的方法。

### 5.5 调研到的硬事实（留档）

- **Renishaw 的标准器具是环规**。手册原文：*"The probe is positioned inside a calibrated ring gauge"*；Z 参数可选，*"If this is omitted, a ring gauge cycle is assumed."* 环规侧壁竖直，高度问题不存在。
- **官方认可"已知位置一次做完"**：*"If the calibration feature is accurately known for both size and position... it is then possible for you to write a program which completes the full calibration procedure in one operation."* → **9805 就是这句话的特例**。
- **存的是触发半径，不是实际球半径**：*"stored radius values are based on the true electronic trigger points. These values are different from the physical sizes."*
- **标定速度必须等于测量速度**（预行程随速度变）。程序里标定用 `#119`（3000 mm/min），后续测量也用 `#119`。
- **DIN 5401 Grade 5**：3～12 mm 球，直径公差 ±5.32 µm，球度 0.13 µm。

## 6. 使用方法

### 6.1 准备

1. 基准球吸在台面（或磁座）上，擦干净，**不许有油、铁屑**；
2. 用中心寻找规找 X / Y，精度到 1～2 µm 就够（球心误差会 1:1 进结果，所以别糊弄）；
3. 用块规 / 对刀块定球顶 Z，`球心 Z = 顶点 Z − Rs`；
4. 探针电池正常，测杆无弯曲，测球无粘屑。

> 也可以把工件坐标系（G54）直接设在球心，这样调用时 `X Y Z` 全省略。

### 6.2 调用

```gcode
G65 P9805 D25.000 T24 R1.500 U10
```

| 字母 | 含义 | 省略时 |
|---|---|---|
| `D` | 基准球**直径** | 必须给（报警 91） |
| `T` | 刀补号 | 必须给（报警 91） |
| `R` | 名义**测球半径**（只定位，不计算） | 用旧触发半径 |
| `Q` | 安全间隙 / 超程 | 5 mm |
| `U` | 粗触顶搜索深度（负值 = 关闭） | 10 mm |
| `K` | Δ 允许上限 | 10 mm |
| `X Y Z` | 球心坐标 | 0（= 工件零点） |

### 6.3 三种场景

| 场景 | 建议写法 | 说明 |
|---|---|---|
| **首次校准**（`#500=0`） | `G65P9805 D25. T24 R1.5` | `R` 很重要，否则平面位置没依据 |
| **换测针**（r 变化大） | `G65P9805 D25. T24 R1.5` | 必须给新的 `R` |
| **日常复核**（同一测针） | `G65P9805 D25. T24` | 不给 `R`，用上次的 #500，行为与老版本完全一致 |

> 因为第一次触球就在赤道（球最宽处），起测点到球面的余量只有 `Q − 球心偏差`。
> `Q` 默认 5 mm，正常装夹偏差 < 0.5 mm 时余量 4.5 mm，很安全；但如果你对球心坐标没把握
> （比如第一次上这颗球、或者球是随手吸上去的），给 `Q10` 更稳。

### 6.4 结果判读

- **连跑两遍**，看 `#500` 两次的差：应 < 2 µm。差得多 → 球没擦干净 / 球没固定 / 测杆松。
- `#500` 与 `#501` 应非常接近（差 < 2 µm），差太多说明测针本身有问题（杆弯了）。
- `#502` / `#503` 与上次比不应有突变。
- 想交叉验证：隔天再跑一次（同一测针、同一颗球），两次 `#500` 应一致在 1～2 µm 内。两次差得多，说明有东西在漂（球、测杆、温度），不是程序的问题。

### 6.5 排查表

| 现象 | 先查什么 |
|---|---|
| 报警 93（没触到） | `R` 是否给太大；球是否放对位置；探针是否打开 |
| 报警 95（偏心超限） | 球心 X/Y 坐标是否填错；球是否没吸牢 |
| 报警 96（半径超范围） | `D` 是否填成半径；是否换错测针；V 是否接近 0 |
| 半径偏大/偏小 0.1 mm 级 | 球心 Z 是否测错（Δ 大了会连带） |
| 重复性差（>5 µm） | 球面清洁、测针刚性、进给速度是否一致 |

### 6.6 适用范围与边界

| 项目 | 说明 |
|---|---|
| 适用 | 三轴（主轴平行 Z），X / Y 两向触发半径 + 偏心 + 长度 |
| 不适用 | 5 轴 / 万向测头需要**矢量表**（`#510`~`#517`），本程序**不写**矢量 |
| 测球尺寸 | 半径门限 0.2～10 mm（即 D0.4～D20）。超出范围会被 96 误拦，需改门限 |
| 球的要求 | 必须刚性固定，运行中不能有位移；球面不许有油、屑、碰伤 |
| 速度 | 标定与后续测量都用 `#119`（3000 mm/min），**不要**为了"稳"而降速，否则预行程不一致 |
