# 9805HB4 测头标定 · 防忘笔记讲解及对比

> 机器：iTNC 530 / TCH PROBE 0（手动探测循环）
> 程序：`9805HB4.H`（316 行，0–315），机上实测通过版
> 这份笔记解决一个问题：**三个月后你还会不会记得为什么这么写。**

>**有一个大坑：校准前刀具表内的xy偏心应该都清除掉，带着刀具表内的偏心和角度进行校准的时候，测头中心的位置是错误的，导致最后的测量结果有误。FN 17: SYSWRITE ID 50 NR24 =0(清除X偏心),FN 17: SYSWRITE ID 50 NR25 =0(清除Y偏心),FN 17: SYSWRITE ID 50 NR26 =0(清除手动环规校准自动输入的角度)。刀具表内的偏心的意思是在测头在该角度下的XY偏心**

---

## 0. 一句话

一次装夹、10 次触发，把一根测针的 **球半径 r、长度 L、偏心 Ex/Ey** 全部量出来并写回刀具表；
表里原来填的是 0、0.2、5 mm 甚至负数，**跑一趟就正**，不用跑第二趟。

```
输出四件套：  Q80 = r      Q81 = |E|      Q82/Q83 = Ex/Ey      Q84 = L
写回刀表：    NR2(R)  NR1(L)  NR24(Ex)  NR25(Ey)
```

## 1. 校准原理

### 1.1 谁是谁：一个已知 + 四个未知

| 量 | 符号 | 大小 | 来源 |
|---|---|---|---|
| 基准球直径 | D = Q1 | 25 mm（千分尺量过） | 输入 |
| 基准球半径 | RS = Q20 = Q1/2 | 12.5 | 派生 |
| 测球半径 | **r** | ≈ 0.963 | **要标定** |
| 测针长度 | **L** | 几十 mm | **要标定** |
| 测球偏心 | **Ex / Ey** | 几十 µm | **要标定** |
| 球心到测球中心距离 | A = RS + r | ≈ 13.463 | 中间量 |

注意：`Q1` 是**基准球**直径（25 mm），不是测球直径。整个程序里 `RS = 12.5` 都是基准球半径。

### 1.2 第一个坑：`0.1` 行填的是"触点"，不是"逼近点"

```
TCH PROBE 0.0 REF. PLANE Q50 X+     ← 结果参数
TCH PROBE 0.1  X+Q33  Y+Q7  Z+Q30   ← 名义触点坐标
```

`TCH PROBE 0.1` 里给的是**理论上触球的那一点**（球面极点）。循环拿到它之后，**自己会沿探测方向再让开一个"刀具半径"**（用刀表 R）才走。所以：

- 填 `Q33 = Q6 − RS`（球面左极点）→ 对。
- 填 `Q29`/`Q25`（之前算的预定位）→ 循环会**再多让一个半径**，站位比触点还靠里，等于预设了一个错位置，量出来的东西带固定偏置。
- **不要把 r 再加到 0.1 行上**，循环已经加过一次了。

### 1.3 第二个坑：侧触平面永远不在赤道上

粗触顶（第 1 次触发）的结果 `Q60` 是循环用**刀表 R** 折算出来的"假定触点"：

```
Q60 = 球心Z + RS + (r − R表)          ← 循环减掉的是表 R，不是真 r
Q30 = Q60 − RS = 球心Z + (r − R表)    ← 四根侧面触针的 Z 高度
```

**所以平面高度 w = r − R表，永远在赤道上方（或下方）**，不是赤道。

实测那一次：表 R 填 0.2、真 r = 0.963 → w = 0.763 mm，四个侧触点全在赤道**上方 0.763**。
这就是为什么"半径输 0.2，跑完小了 0.02 多"——半宽量到的是一根**弦**，不是直径。

### 1.4 第三个坑：半宽是弦长 —— 闭式解的由来

侧触瞬间，测球中心 P 到球心 C 的距离**恒等于 A = RS + r**（球尖永远贴在球面上）。
平面高度 w 已知（w = r − R表），所以水平投影（就是半宽 m）：

```
m² = A² − w²
```

又因为 `w = r − R表 = (RS + r) − (RS + R表) = A − K`，其中 `K = RS + R表`：

```
m² = A² − (A − K)² = 2KA − K²
→  A = (m² + K²) / (2K)          ← 程序 218–229 行就是这四步
→  r = A − RS
```

这就是 9805HB4 半径块的全部。**K 必须用表 R**，因为循环就是拿表 R 补的；用真 r 去凑反而不自洽。

验算（表 R = 0.2，真 r = 0.963）：

| 步骤 | 值 |
|---|---|
| A = RS + r | 13.463 |
| w = r − R表 | 0.763 |
| m = √(A² − w²) | 13.4413 |
| 老公式 `r = m − RS` | **0.9413（−21.7 µm）** ← 你测到的"小 0.02 多" |
| 新公式 `A = (m²+K²)/2K` | 13.4630 → **r = 0.9630（0 µm）** |

球心还输偏了 2 mm 那一次：老公式 0.8058（−157 µm，你看到的"0.8 多"），新公式 0.9632（+0.2 µm）。

> 一句话记住：**`r = m − RS` 只在"平面正好过赤道且球心正好准"时成立；两个条件在这台机上都不成立，所以必须解方程。**

### 1.5 球心偏了怎么办：0° 与 180° 对劈

偏心 E 的定义：测球中心相对主轴轴线偏了 (Ex, Ey)。

`Cycle 0` 在每次触发前，会把刀表 24/25 列按当前主轴角度投影后**加进触发坐标**。所以读回来的"球心"是：

```
Q63 = C + e − E = C − (E − e)      ← 0°：表值 e 与真实 E 之差
Q65 = C − e + E = C + (E − e)      ← 180°：投影反向
```

- 两个一劈：`Q82 = (Q65 − Q63)/2 = E − e`（**残差**），`Q86 = Q63 + Q82 = C` —— 恒等于真球心，**与表里 e 填什么无关**（199–200 行）
- 半宽相反：两下是**等量平移**，在差值里自己抵消，所以 `MX = (Q51−Q50)/2` 与偏心无关 ✔

> 注意区分两个 E：`Q81` 是**残差模长**（表里校正量之外还剩多少），不是绝对偏心。表里已经准了，`Q81` 就该接近 0。

**Q12 = 0 时没有 180° 那一组**，只能拿你输入的 `Q6/Q7` 当真球心。此时：
球心偏 d0 ⟹ r 的误差 ≈ d0²/(2·A)，2 mm 就吃掉 150 µm。**所以 Q12=0 只能用于"球心已经确认准"的复查场合。**

### 1.6 偏心为什么必须"增量写"

24/25 列的语义是**校正量**，不是"实测偏心"：循环会把它加回去。所以写绝对值 = 把残差当新值，

```
增益 = −1  ⟹  每跑一次符号翻一次，永远不收敛
```

实测证据：填 +0.5 / +0.5，跑一趟变成 **−0.4986 / −0.5111**（≈ −输入），第二趟又翻回来。

改成**增量**：

```
新值 = 旧值 + 残差      （290–291 行：Q43 = Q45 + Q82）
```

一趟到位，第二趟残差 ≈ 0，不再动。这是整个程序里最容易忘、也最要命的一条。

### 1.7 为什么 R 必须先写表，再测 L

极点触顶的结果同样是"假定触点"：

```
Q73 = 球心Z + RS + (r − R表)
Q76 = Q73 − Q19 = ΔL + (r − R表)
```

- **先写 R**（259–260 行）→ 表 R 此时已经等于测得的 r → `(r − R表) ≈ 0` → `Q76` 就是纯 ΔL → `Q84 = L + ΔL`，一次到位。
- **若先测 L 再写 R** → 必须补 `(r − R表)` 这一项，老版本的 `Q77 = Q80 − Q2` 就是补它；两个顺序配套，删了一个就必须改另一个。

这也是为什么表格 R 填错 0.7 时，老版本"第一趟 L 短 0.7、第二趟自己回来"——那是 `Q77` 多减了一次，不是机床的毛病。

### 1.8 L 的基准：Q8 是"1:1"进来的

`Q19 = Q8 + RS` 是球顶名义 Z，`Q76 = Q73 − Q19`。所以 **Q8 差多少，L 就差多少，一阶线性，没有平方项**。
Q8 必须来自量块/对刀仪的实测球心 Z，不能"看着差不多"。这也是唯一一个输入错了会让整台机床 Z 偏掉的参数。

## 2. 实现方法

### 2.1 主流程

```
                      ┌─ 输入 Q1 Q3 Q4 Q5 Q6 Q7 Q8 Q12
                      ├─ 读刀表 L R DL DR（无 IDX = 当前刀）
                      ├─ L < 5 ? ──是──▶ LBL902  Q91=-3 停
                      └─ 派生 RS / 球顶 / 站位 / 触点坐标
                                  │
                 CYCL DEF 13.1 ANGLE0 + M19   ← 主轴先归 0°
                                  │
                        ① 粗触顶 Z−（Q60）→ Q30 = Q60 − RS 定平面
                                  │
            ② 0°  X+ X− Y+ Y−    → Q50 Q51 Q52 Q53
                                  │
                  Q12 > 0.5 ? ──否──▶ Q54..Q57 = Q50..Q53 跳过 180°
                                  │是
                 CYCL DEF 13.1 ANGLE180 + M19 + MP6161=0
            ③ 180° X+ X− Y+ Y−   → Q54 Q55 Q56 Q57
                 ANGLE0 + M19 + MP6161=19  ← 恢复原值
                                  │
              半宽 → 球心 → 偏心 → 真球心(Q86/Q87)
                                  │
             判分裂 Q91=−2（仅 Q12=1 且 Q81<0.01）
                                  │
                      闭式解 r（Q80）
                                  │
               r>10 或 r<0 ? ──是──▶ LBL902  Q91=-3 停
                                  │否
                       写 R（NR2）  ← 必须先写
                                  │
            读 24/25 → 真极点 Q37/Q38 → ④ 极点触顶 Z−（Q73）
                                  │
                  Q73 还是 99999 ? ──是──▶ LBL903  Q91=-4 停
                                  │否
                       Q76 = Q73 − Q19 = ΔL → 写 L（NR1）
                                  │
               Q91 ≥ 0.5 ? ──否──▶ 跳过偏心写
                                  │是
                  Q43/Q44 = 旧 + 残差 → 范围检查 → 写 NR24/25
                                  │
                        L Z+Q5 → M0（看数）→ M30
```

### 2.2 九段与行号索引

| 段 | 行号 | 干什么 | 关键量 |
|---|---|---|---|
| 输入 | 22–30 | 调刀、给 8 个输入 | Q1 Q3 Q4 Q5 Q6 Q7 Q8 Q12 |
| 读刀 | 32–37 | 读 L R DL DR，算有效值 | Q2 Q11 Q15 Q16 |
| L 闸门 | 39–40 | L<5 当空列，直接停 | Q95 |
| 派生 | 42–57 | RS、球顶、站位、触点 | Q19–Q36 |
| 定向 | 61–63 | 主轴归 0° | — |
| 粗触顶 | 65–74 | 找平面 | Q60 → Q30 |
| 0° 四向 | 76–102 | 量两根弦 | Q50–Q53 |
| 180° 段 | 104–152 | 换向再量（含 MP6161 两句） | Q54–Q57 |
| 计算 | 154–245 | 半宽→球心→偏心→r | Q58–Q98 |
| 写表 | 246–302 | R → L → Ex/Ey | Q32 Q31 Q43 Q44 |

### 2.3 主轴定向：三段，缺一不可

| 行 | 语句 | 为什么 |
|---|---|---|
| 61–63 | `CYCL DEF 13.1 ANGLE0` + `L M19` | 上电后主轴角度是"上一支程序留下的"，不归零则 24/25 的投影方向全错 |
| 112–114 | `ANGLE180` + `M19` | 转到 180°，让偏心在触发坐标里反向 |
| 147–149 | `ANGLE0` + `M19` | 回 0°，否则后面极点触顶和下次加工的定向都变了 |

### 2.4 MP6161 的两处写入（这次新加的，专治"自动回 0°"）

```heidenhain
112  CYCL DEF 13.0 ORIENTATION
113  CYCL DEF 13.1 ANGLE180
114  L M19
115  FN 17: SYSWRITE ID 1000 NR6161 =+0     ← 临时改成 0
116  CYCL DEF 9.0 DWELL TIME
117  CYCL DEF 9.1 DWELL1                    ← 等 1 s 让参数生效
...
147  CYCL DEF 13.0 ORIENTATION
148  CYCL DEF 13.1 ANGLE0
149  L M19
150  FN 17: SYSWRITE ID 1000 NR6161 =+19    ← 恢复原值
151  CYCL DEF 9.0 DWELL TIME
152  CYCL DEF 9.1 DWELL1
```

**症状**：180° 段程序明明写了 `ANGLE180`，四个触点却全落回 0°。
**后果**：0° 和 180° 两组数据重合 → `Q81 ≈ 0` → `Q91 = −2`，偏心写不进（或写入 0），看起来就是"偏心永远不收敛"。

**机理**：本机把 MP6161 当作"探测前的主轴定向角"用，循环每次触发前会按它重新定向，把 `CYCL DEF 13.1` 的结果顶掉。写 0 之后不再强制回转，主轴就老老实实停在 180°。跑完必须写回 **19**（本机原值）。

> ⚠️ **三条铁律**
> 1. **换机先抄原值**：19 是本机的数，别的机器不一样。改之前先 `SYSREAD` 或手抄。
> 2. **中途别拍复位/断电**：程序停在 115–150 行之间时，参数还留在 0。恢复后手工改回 19，否则下一次探测的定向行为是错的。
> 3. **写不进去就认命**：参数被锁/权限不足时 `SYSWRITE` 无声失败，180° 段等于在 0° 量 → 全靠 `Q91 = −2` 兜底。看到 −2 先查 MP6161。

**另一个观察（未改，仅记录）**：0° 段（76–102 行）是在 MP6161 还是原值 19 的情况下跑的。如果你的机器按 19° 定向，那么 0° 组其实是 19° 组。实测精度没受影响（半径公式与角度无关），但**偏心的角度基准会差 19°**。要更严格就在程序最开始也写一次 0，但那会改动已经验证通过的流程 —— **先记着，别动。**

### 2.5 18 → 4：中间量怎么收成结果

| 结果 | 公式 | 行 |
|---|---|---|
| MX@0 / MY@0 | `(Q51−Q50)/2`、`(Q53−Q52)/2` | 155–158 |
| MX@180 / MY@180 | `(Q55−Q54)/2`、`(Q57−Q56)/2` | 159–162 |
| 球心@0 | `Q63 = (Q50+Q51)/2`、`Q64` | 164–167 |
| 球心@180 | `Q65 = (Q54+Q55)/2`、`Q66` | 168–171 |
| Ex / Ey | `(Q65−Q63)/2`、`(Q66−Q64)/2`（Q12=0 时用 `Q6−Q63`） | 173–182 |

| 真球心 | `Q86 = Q63+Q82`、`Q87 = Q64+Q83` | 199–200 |

**半宽必须"大减小"**：X+ 从 −X 侧出发触左边，所以 `Q50 < Q51`。写成 `Q50−Q51` 会得到负半径（老版本踩过）。

### 2.6 状态码与三个出口

| Q91 | 含义 | 行为 |
|---|---|---|
| **+1** | 正常 | 写 R、L、Ex/Ey，M0 看数 |
| **−2** | 0°/180° 分裂 < 10 µm：主轴没转过去，或表里本来就有校正量 | **不停机**，写 R/L，跳过 24/25 |
| **−3** | 刀表 L < 5（空列），或 r 出界（>10 或 <0） | LBL902，M0 停 |
| **−4** | 极点触顶没跑（`Q73` 还是哨兵 99999） | LBL903，M0 停 |

`−2` 故意不停机：残差本来就可能是 0（表已准），停机反而挡路。
`−4` 要有哨兵才能判：`Q73 = 99999` 先塞进去，循环不跑就没人改写它（275 行）。

## 3. 使用说明

### 3.1 上机前检查清单（每次）

- [ ] **MP6165 = 0**（探测时不补偿刀具半径）；**MP6161 记下原值**（本机 19）
- [ ] `TOOL CALL 11 Z` —— 第 22 行的刀号对不对（本机测头是 11 号刀）
- [ ] 刀表里这把刀有 **L**（没有会走到 LBL902），**R 随便填**
- [ ] 24/25 列（Ex/Ey）**随便填**，包括垃圾值
- [ ] 基准球吸牢、球面擦干净，**D 用千分尺量**（不要用铭牌 25.000）
- [ ] `Q8` = 球心 Z，用**量块/对刀仪**得，别估
- [ ] 刀具长度补偿必须在当前刀上（程序读的是"当前刀"）

### 3.2 输入怎么给

| 参数 | 含义 | 给法 | 给错的后果 |
|---|---|---|---|
| `Q1` | 基准球直径 | 千分尺实测，如 25.000 | r 直接错 Q1/2 的差 |
| `Q3` | 球顶上方余量 | 2 mm | 太小会撞，太大慢 |
| `Q4` | 侧向余量 | 2 mm | 同上 |
| `Q5` | 安全 Z（当前坐标系） | 60 | 太小会撞夹具 |
| `Q6/Q7` | 球心 XY | Q12=1 可粗（±2 mm 都行）；**Q12=0 必须准到 0.05** | Q12=0 时 r 按 d0²/2A 掉 |
| `Q8` | 球心 Z | 量块实测 | L 1:1 跟着错 |
| `Q12` | 1 = 0°+180°；0 = 只跑 0° | **平时用 1** | 0 只适合复查 |

### 3.3 一次运行的节奏

```
Q12=1：10 次触发   ≈ 3–5 min
  ① 粗触顶  ② 0°×4  ③ 180°×4  ④ 极点触顶
Q12=0： 6 次触发
```

结束时 `M0` 停，屏幕上是 `Q80 Q81 Q82 Q83 Q84 Q85 Q91`，抄下来再按循环启动。

### 3.4 结果怎么读

| 参数 | 含义 | 正常范围 | 判读 |
|---|---|---|---|
| `Q80` | 测球半径 r | 0.5–3 mm | 与铭牌差 < 20 µm 正常 |
| `Q81` | 偏心模长 \|E\| | 0–0.3 mm | > 0.5 说明撞过/装歪 |
| `Q82/Q83` | Ex / Ey（残差） | 几十 µm | 第二趟应 ≈ 0 |
| `Q84` | 新 L | 与旧 L 差 < 3 mm | 差太多说明 Q8 错了 |
| `Q85` | ΔL | ±3 mm | 就是这次 L 该改多少 |
| `Q91` | 状态 | +1 | 见 2.6 |

### 3.5 异常对照表

| 现象 | 大概原因 | 处理 |
|---|---|---|
| `Q91 = −2` | 180° 没转过去 / MP6161 没写进去 / 表里已有校正量 | 查 MP6161；表清零后重跑 |
| `Q91 = −3` | 刀表没 L，或 r 算出 0/负/>10 | 补 L；查 Q1 是否给成测球直径 |
| `Q91 = −4` | 极点触顶没触发 | 查球顶高度、`Q3`、探针是否断 |
| r 每趟都变几十 µm | 球面脏 / 球没吸牢 / 转速未停稳 | 擦球、重吸、等 2 s 再跑 |
| 偏心符号每趟翻 | 用了覆盖写而不是增量写 | 检查 290–291 行 |
| L 每趟差同一个值 | Q8 错（1:1 进 L） | 用块规重对 Q8 |
| 半径永远差 0.02 多 | 用了 `r = m − RS` 而不是闭式解 | 检查 212–245 行 |

### 3.6 六个坑（血泪版）

1. **`0.1` 行填触点，不填逼近点**，也不要自己加 r。
2. **半宽要"大减小"**，反了就是负半径。
3. **偏心只能增量写**，覆盖写必然符号翻转。
4. **R 必须先写表再测 L**，顺序换了公式就得改。
5. **极点触顶要在真极点**（`Q63 − 表Ex`），偏 δ 就吃 δ²/2RS 的斜坡误差。
6. **`Q1` 是基准球，不是测球** —— 这个错最贵。

## 5. 与 Mazak O9804 的异同

Mazak 侧对应的是 `O9804 (REN CAL VEC STYLUS RAD)` + 宏 9721/9722/9724/9726/9727（Renishaw Inspection Plus 那套）。

### 5.1 一句话对比

| | Mazak O9804 | 9805HB4 |
|---|---|---|
| 本质 | **矢量半径标定**：量 8 个方向的半径偏差，存成角度表 | **三合一标定**：解 r / L / E，写回刀表 |
| 输出 | `#500`–`#517`（每 30° 一个修正量） | 刀表 4 列：R、L、24、25 |
| 谁去用这些数 | 后续测量循环按探测方向查表 | 系统自己按刀表补 |

### 5.2 相同的六件事

1. **都以基准球为基准**：O9804 输入 `D`(#7) 缺了直接报警 91；HB4 输入 `Q1`。
2. **都先找球心**：O9804 用 X±/Y± 对触取中点 `#127/#128`；HB4 用 0°/180° 四向 + 对劈。
3. **都用"实测触发点 − D/2"当修正量**：O9804 `ABS[#7/2 − ABS[#124−#127]]`；HB4 的 `m` 就是同一件事的弦长版。
4. **都要求刀具长度补偿已生效**：O9804 查 `#4008=49` 否则报警 89；HB4 靠 `TOOL CALL` + `SYSREAD ID50 NR1`。
5. **都有"没触到"的监控**：O9804 用 `#123=0.005` 到位窗口 + `#149` 错误码 + 报警 91/92/93；HB4 用 `Q73` 哨兵 + `Q91`。
6. **结束都回安全位**：O9804 `G0X#10Y#12`；HB4 `L Z+Q5` + `M0`。

### 5.3 不同的十件事

| 维度 | Mazak O9804 | 9805HB4 | 影响 |
|---|---|---|---|
| 语言 | Fanuc 宏 B（EIA） | 海德汉 Q 参数 + 固定循环 | 不能互抄 |
| 方向数 | 8 个矢量方向 + 4 个对触点 | 4 个对触点 + 1 个极点 | 触发次数相近（10–12 次） |
| 半径模型 | 直接 `\|D/2 − 实测距离\|`，线性 | 闭式解，含平面高度与球心偏差 | HB4 一次到位；9804 的偏差定义本身就是"该方向的等效半径" |
| 偏心 | **不管**，被吃进矢量表 | 显式解 Ex/Ey 并写刀表 | 见 5.4 |
| 表写入 | 每次先 `#135..#148 = #0` 清空，再**绝对写** | 24/25 必须**增量写** | 语义相反，照搬必出错 |
| 探测指令 | `G31` 跳跃 + 后退 + 二次低进给（P9726 里触两下） | `TCH PROBE 0.0/0.1` 单次触发 | 9804 抗污能力强 |
| 读数 | `#5061/#5062/#5063`（跳跃瞬间机床坐标） | `Q115/Q116`（已含 24/25 投影）+ `Q73` | HB4 读到的是残差不是绝对值 |
| 出错 | 直接报警停机（`#3000=9x`） | 不停机，写 `Q91` 状态码 | HB4 能"降级继续" |
| 单位 | `#4006` 分支 mm/inch，`#129` 系数 | 固定 MM（程序头写死） | — |
| 参数存放 | 宏变量 `#500` 区（掉电保持） | 刀表列（系统统一管理，换刀自动跟） | — |

> O9804 的矢量角度是 30/60、120/150、210/240、300/330 —— 刻意绕开 0/90/180/270：那四条轴线由前面的 X±/Y± 对触负责，矢量表只填"斜方向"的空。

### 5.4 为什么 HB4 必须显式管偏心，9804 不用

O9804 的修正量定义是"**从实测球心到触发点的距离，与 D/2 的差**"。偏心让触发点整体平移 —— 平移在"某个方向的距离"里表现为该方向的半径偏差，于是**偏心被自动吸收进矢量表**。代价是：这只在"按同角度探测"时对得上，换个角度就得查表的另一格。

海德汉这边不行：`Cycle 0` 会把 24/25 **投影后加到每一个触发坐标**上，你不显式减掉它，它就会污染球心（`Q63 = C − E`），而球心一旦错，`Q12=1` 的对劈就退化成 `Q12=0`，2 mm 的球心误差能吃掉 150 µm 半径。所以 HB4 必须先把 E 解出来、真球心 `Q86/Q87` 定死，半径块才有意义。

反过来说：**9804 的矢量表适合"多方向测量"，HB4 的四个数适合"一把刀走天下"**。海德汉的测量循环只认刀表 R/L，没有"按角度查半径"的机制，所以只能把偏心折进 24/25，让系统每次触发时自己转。

### 5.5 互相能借什么

- **9804 → HB4**：二次低进给重触（P9726 里触两下取第二下）。HB4 现在是单次触发，球面有油膜时会有 3–5 µm 抖动，加一次"后退 8×余量再慢速重触"能压下去。代价：每次多 8 行、多一倍时间。
- **9804 → HB4**：到位窗口监控（`#123`）。HB4 只判"有没有触发"，没判"触发得离不离谱"，可以加一条 `|Q115 − 名义触点| > 2×R` 就停。
- **HB4 → 9804**：闭式解。如果哪天在马扎克上发现"平面不在赤道"导致的半径偏差，把 `(m²+K²)/2K − RS` 换进 `#[#4+#5]` 那一行即可。
